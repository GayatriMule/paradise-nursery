# Paradise Nursery

Paradise Nursery is a React and Redux-based online plant shopping application.

## Project Description

Paradise Nursery is an online plant shop where users can browse different categories of houseplants, add plants to a shopping cart, manage quantities, remove items, and view the total cart amount.

The application is built using React, Redux Toolkit, and Vite.

## Features

- Paradise Nursery landing page
- Company information / About Us section
- Plant product listing page
- Three plant categories
- Six unique plants in each category
- Plant images, names, and prices
- Add to Cart functionality
- Cart item counter
- Disable Add to Cart button after adding a product
- Increase and decrease product quantity
- Delete products from cart
- Individual product total calculation
- Overall cart total calculation
- Checkout button with Coming Soon message
- Continue Shopping button
- Navigation between Home, Plants, and Cart pages
- Responsive user interface
